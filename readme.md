## 🚀 The TL;DR
I am a Software Engineering student and Full-Stack Developer based in Sri Lanka. By day, I handle application support for complex banking systems and build immersive, highly interactive web experiences using **React, Next.js, GSAP, and Three.js**. 

Beyond the web, I dive deep into the machine. I am heavily invested in low-level programming, network security, and mathematics, currently transitioning into real-time audio software and Digital Signal Processing (DSP) using **C++ and JUCE**. 

When I'm not writing code or analyzing network packets, you can find me producing EDM and Hip-Hop under my music brand, **LDMRK**.

---

## ⚡ What I'm Currently Up To
- 💻 Building animated frontends and robust `.NET` backends for complex web applications.
- 🎛️ Mastering **C++**, **JUCE**, and DSP mathematics for custom audio plugin development.
- 🎵 Dropping beats and tutorials on the **LDMRK** YouTube channel.
- 🔐 Deepening my knowledge in Data Structures, Algorithms, and network packet analysis.
